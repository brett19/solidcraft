#### Updates: WR-80 (2026-11-14). The advanced intersector traces back through the shared method

- **Change:** `SmAdvSurfaceIntersector::FindInteriorCurves` (`intersect/adv_surface_intersector.rs`) traced a curve back with its own reverse/trace/reverse block, without the "something was traced" condition: the gap the 2026-11-05 addendum left open. Its trace from a start point is now one function, `trace_both_ways`, whose trace-back is `SurfaceIntersector::trace_back` (`surface_intersector/p4.rs`), the method `FindInteriorCurves` and `DoIntersection` of the basic intersector already use. A trace that produced points is traced back exactly as before.
- **Reach:** without `ssi_low_angle_start_on_probation` no start point reaches the empty trace there. A start point whose normals are within 2 degrees is skipped, so no traced start point is a tangent or coincidence point, and `TraceCurve` puts every other start point on the curve; `TraceCurve` clears the curve only for a bounded start point, which is not traced back. SolidCraft's kernel turns `ssi_low_angle_start_on_probation` on (`tests/kernel_cases/fixes.json` lists it). Then a start point whose normals are within `EFF_ZERO_RAD` (and above `2 tol / modelSize`) can be a tangent point (`ComputeSingularityPoint`); like a coincidence point, it leaves the curve empty when its mean point (`crv_pos`) lies on a found curve while its point on the first surface, which the loop tests before tracing, does not. Both are points of one local solution and nearly coincide, so no case with a closed-form answer is known to fall between the two tests.
- **Tests:** `adv_surface_intersector::tests::tangent_start_on_a_found_curve_is_not_traced_back` traces a tangent start point at `(0.5, 0.5, 0)` that lies on a found single-point curve there; on the old block it fails with `SM_ERR_NULL_POINTER` from `reverse_curve_direction`, now the curve stays empty and open and the direction stays `1.0`. `crossing_start_is_traced_both_ways` traces the crossing of the planes `z = 0` and `y = 0.5` from `x = 0.5` and checks that the trace back still runs: the points reach both ends `x = 0` and `x = 1`, lie on the line and are in order along it.
- **Goldens:** unchanged, as the reach above says.
